# TV playback layout stability

An ordinary listening-progress save must not add an unanswered-save warning or briefly move the title, cover, or controls on Now Playing. Playback ticks must leave the home shelf stationary. A genuine unknown save outcome must still show the existing warning and recovery actions without recentering the playback hero.

Keep the durable progress ordering barrier, journal format, account identity, credentials, relaunch recovery, and server restart confirmation unchanged. Live transmissions remain ordering barriers; only their presentation distinguishes them from transmissions whose answer is unknown. After relaunch any retained transmission is unknown.

Ship a TV-only patch to the paired owner TV without launching or resetting it, and prepare the next internal TestFlight TV build. Do not upload an iOS replacement or submit a public store release as part of this patch. Preserve tvOS 17 support and native focus navigation. Run verification without screenshots.

Acceptance uses synthetic HTTP and remote-driven TV journeys: a delayed successful save, an unanswered save, home playback ticks, persisted listening, and server restart recovery. Observe failing position assertions before fixing each layout transition.
