# Leafwake Android listing draft

Name: Leafwake

Short description: A native player for your Audiobookshelf library.

Connect to your own Audiobookshelf server and listen to your audiobook and podcast library. Leafwake is an independently maintained native client. An existing Audiobookshelf server is required; no books or subscriptions are supplied by the app.

The first public version is a beta. Final feature claims and supported server versions must match the verified release artifact. Do not advertise Chromecast, Apple Watch, Android TV, or deferred reader formats for the Cast-free Android beta.

Leafwake is not affiliated with or endorsed by the Audiobookshelf project. Source code is available under GPLv3, with the applicable licenses for included third-party components retained.

Developer contact, content rating, Data safety form, exact screenshots and the reachable review-server account must be completed against the actual publishing account before submission. Do not copy upstream metadata or use screenshots from private libraries.
