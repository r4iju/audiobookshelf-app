# Leafwake release status, October 5, 2026

## Backend and browser

The replacement backend and Next.js browser run in one production image on one listener, including REST, Socket.IO, media and durable jobs. Reviewed PR #201 removed the active Nuxt/Vue/Capacitor runtime and old backend launch/patch dependencies. Native clients, read-only migration readers, licenses and historical evidence remain.

Registry publication is not claimed; the published Docker archive is the distribution artifact.

The owner installation at `https://audiobookshelf.nginx.lan` was cut over to rc.2 on TrueNAS. Only the new Leafwake deployment remained active; both original apps were stopped with zero pods. A closed snapshot preserved the original owner ID/password, 127 library items, 34 listening records and 127 covers. Migration reported no unsupported data or errors. A fresh backup was restored separately and checked for integrity and identity. Original data and ingress configuration were retained for rollback.

After that successful cutover, NAS `192.168.0.100` became unreachable. SSH timed out and the router could not resolve the host through ARP; the HTTPS ingress now returns 502. The later rc.3 transfer never connected, and no rc.3 image or configuration update was applied. No hardware cause is established. Host recovery and a verified final image update remain open; current live health is not claimed.
