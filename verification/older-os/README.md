# Original Apple OS verification

The pinned native workflow selects official Xcode15.4/Swift5.10/SDK17.5 on an arm64 macOS14 runner. Independent jobs build the original iOS14 simulator minimum, replay seven existing TV17 remote methods, and attempt the original Apple-signed iOS14.5/18E182 runtime before six unchanged iOS journeys. A rejected stock installer or unavailable runtime is a capability failure, never an accepted skip. No runtime patch, mirror, minimum raise, private signing or physical release acceptance is implied.

Every job verifies the exact triggering clean source, records actual toolchain/runtime/binary minima and commands, preserves original results within250MiB and releases owned pool leases. Jobs are bounded40/75/30min (145 summed; nominal75 parallel plus queue). Parent owns the narrowly controlled GitHub Actions enable/trigger/restoration window.
